# Школьная служба медиации — ГБОУ СОШ № 84

Статический сайт службы. Сборка не нужна: достаточно выложить папку на хостинг.
Подготовлен для публикации на **GitHub Pages** (все пути относительные — сайт
работает и в корне домена, и в подкаталоге вида `https://<логин>.github.io/<репозиторий>/`).

## Что сделано в этой версии

- **Кнопки скачивания в разделе «Документы» работают**: каждая кнопка ведёт на
  реальный PDF в `assets/docs/` (атрибут `download` сохраняет файл с тем же именем).
- **Панель «Версия для слабовидящих» выезжает на любом месте страницы**: панель
  закреплена под шапкой (`position: fixed`), поэтому открывается и остаётся видимой
  при любой прокрутке; сама панель при необходимости прокручивается внутри.
- **Вместо крестика — слово «Закрыть»**: и в панели настроек, и в окне просмотра
  фотографий (лайтбоксе).
- **Полная адаптация для мобильных устройств**: заголовок и кнопки первого экрана
  перестраиваются в столбец, карточки документов получают увеличенные (44 px)
  цели касания, команды и разделы на узких экранах перестраиваются в одну
  колонку, длинные адреса e-mail переносятся без поломки вёрстки.

## Страницы

- `index.html` — главная и раздел «О службе»: приём заявителей, порядок подачи и рассмотрения заявления, принципы медиации, документы (якоря `#documents` и `#procedure`);
- `team.html` — команда;
- `achievements.html` — достижения;
- `gallery.html` — галерея;
- `video.html` — видеоматериалы;
- `about.html` — перенаправление на главную (старые ссылки продолжают работать).

## Публикация на GitHub Pages

### Способ 1 — из ветки (самый простой)

1. Создайте репозиторий и загрузите в него все файлы этой папки (содержимое — в корень репозитория).
2. В репозитории откройте **Settings → Pages**.
3. В блоке «Build and deployment» выберите **Source: Deploy from a branch**, ветку `main`, папку `/ (root)` и сохраните.
4. Через 1–2 минуты сайт будет доступен по адресу `https://<логин>.github.io/<репозиторий>/`.

### Способ 2 — через GitHub Actions

В папке уже лежит workflow `.github/workflows/pages.yml`. В **Settings → Pages**
выберите **Source: GitHub Actions** — при каждом пуше в `main` сайт будет
пересобираться и публиковаться автоматически.

Файл `.nojekyll` в корне отключает обработку Jekyll — ассеты (`assets/…`) публикуются как есть.

## Версия для слабовидящих

Кнопка «Для слабовидящих» с изображением глаза в шапке открывает панель настроек.
Панель закреплена под шапкой и выезжает на любой позиции прокрутки.

- размер шрифта — 100 %, 125 % или 150 %;
- цветовая схема — обычная, чёрно-белая, тёмная или жёлтый текст на чёрном фоне;
- изображения — показывать, в чёрно-белом виде или скрыть;
- увеличенный интервал между буквами.

Настройки сохраняются в `localStorage` под ключом `sh84-a11y` и действуют на всех
страницах. Кнопка «Обычная версия» в панели сбрасывает их, «Закрыть» — скрывает
панель (работает и клавиша `Esc`). Разметка панели продублирована на каждой странице.

## Локальный просмотр

```bash
python3 -m http.server 8765
```

Затем откройте `http://localhost:8765`.

## Структура

- `assets/css/styles.css` — оформление;
- `assets/js/script.js` — мобильное меню, тень шапки, просмотр изображений;
- `assets/js/a11y-init.js` — раннее применение сохранённых настроек;
- `assets/js/a11y.js` — панель «Версия для слабовидящих»;
- `assets/docs/` — документы в PDF (то, что скачивают кнопки раздела «Документы»);
- `assets/img/` — фотографии галереи и изображения наград;
- `assets/fonts/` — шрифт Manrope;
- `assets/favicon.svg` — значок сайта;
- `.nojekyll`, `.github/workflows/pages.yml` — файлы для GitHub Pages.

## Что где менять

- **Команда** — `team.html`: ФИО, класс и инициалы в карточках.
- **Фотографии участников** — положите файл в `assets/img/` и замените блок
  `<div class="member__photo member__photo--initials">…</div>` на
  `<div class="member__photo"><img src="assets/img/имя.jpg" alt="ФИО" loading="lazy"></div>`.
- **Галерея** — `gallery.html`: изображение, подпись в `figcaption` и `data-caption` для просмотра.
- **Достижения** — `achievements.html`: изображение, год, заголовок и описание.
- **Документы** — `index.html`, блок `#documents`: название, ссылка и размер файла.
  Кладите новый PDF в `assets/docs/` и указывайте его путь и в ссылке-названии,
  и в кнопке скачивания.
- **Порядок обращения** — `index.html`, блок `#procedure`: часы приёма, шаги и сроки.

## Важно: фотографии-заглушки

Файлы в `assets/img/` (5 наград и 3 фото галереи) — временные заглушки с подписью,
потому что исходные фотографии не были переданы. Сайт работает корректно, но перед
публикацией положите рядом реальные изображения с теми же именами файлов:

- `assets/img/gallery-1.jpg`, `gallery-2.jpg`, `gallery-3.jpg` (пропорции 4:3);
- `assets/img/award-2023-video.jpg`, `award-2020-jury.jpg`, `award-2020-video.jpg`,
  `award-2020-pages.jpg`, `award-2020-polunina.jpg` (вертикальные, пропорции 566×800).
