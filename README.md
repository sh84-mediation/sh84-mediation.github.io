Сайт школьной службы медиации ГБОУ СОШ № 84 имени дважды Героя
Советского Союза П. А. Покрышева (Петроградский район Санкт-Петербурга).

**Адрес сайта:** <https://sh84-mediation.github.io/>

Чистый HTML/CSS/JS без фреймворков и сборки: любая правка вносится
редактированием файла и сразу попадает на GitHub Pages. Все пути относительные,
шрифты и стили лежат локально — сайт открывается даже без интернета.

## Страницы

| Файл | Содержимое |
| --- | --- |
| `index.html` | Главная: приём заявителей, порядок подачи и рассмотрения заявления (`#procedure`), принципы медиации, документы (`#documents`) |

| `404.html` | Страница ошибки с возвратом на главную |
| `about.html` | Перенаправление на главную (старые ссылки продолжают работать) |

## Возможности

- **Адаптивная вёрстка** — от 320 px до широких экранов: меню, карточки
  и таблицы перестраиваются, цели касания увеличены (44 px).
- **Версия для слабовидящих** — кнопка с изображением глаза в шапке:
  размер шрифта (100/125/150 %), цветовые схемы (обычная, чёрно-белая,
  тёмная, жёлтая), режим изображений, увеличенный интервал между буквами.
  Настройки сохраняются в `localStorage` (`sh84-a11y`) и действуют на всех страницах.
- **Уважение к `prefers-reduced-motion`** — декоративные анимации отключаются,
  если в системе включено уменьшение движения.
- **SEO-базис**: `canonical`, Open Graph и Twitter Card на каждой странице,
  `robots.txt`, `sitemap.xml`, социальное превью `assets/img/og-image.png` (1200×630).
- **Часы приёма на главной** — бейдж «идёт приём / приём закрыт» считается
  по расписанию (среда, пятница 15:00–17:00; четверг 10:00–12:00).

## Пасхалки

На сайте есть несколько игровых эффектов:

| Действие | Что происходит |
| --- | --- |
| Код Konami: `↑ ↑ ↓ ↓ ← → ← → B A` | Полноэкранный «падающий код зелёных» (матрица) |
| Два пальца по карточке приёма (телефон) | «Арка согласия»: две ленты сходятся к карточке, рисуется галочка в круге |
| Встряска телефона | Конфетти-взрыв (150 частиц) |
| Двойной клик по пустому месту | Конфетти в точке клика — работает на любом устройстве и в любом разделе |

## Публикация на GitHub Pages

Репозиторий называется `sh84-mediation.github.io`, поэтому сайт публикуется
в корне домена **<https://sh84-mediation.github.io/>** — дополнительный путь
в URL не нужен.

### Способ 1 — из ветки (самый простой)

1. Загрузите все файлы в корень репозитория.
2. **Settings → Pages → Build and deployment**.
3. **Source: Deploy from a branch**, ветка `main`, папка `/ (root)` — сохраните.
4. Через 1–2 минуты сайт обновится.

### Способ 2 — через GitHub Actions

В репозитории лежит workflow `.github/workflows/pages.yml`. В
**Settings → Pages** выберите **Source: GitHub Actions** — при каждом пуше
в `main` сайт будет публиковаться автоматически.

Файл `.nojekyll` в корне отключает обработку Jekyll — ассеты
(`assets/…`) публикуются как есть, без обхода папок с подчёркиванием.

## Локальный просмотр

```bash
python3 -m http.server 8765
```

Затем откройте <http://localhost:8765>.

## Что где менять

- **Команда** — `team.html`: ФИО, класс и инициалы в карточках.
- **Фотографии участников** — положите файл в `assets/img/` и замените блок
  `<div class="member__photo member__photo--initials">…</div>` на
  `<div class="member__photo"><img src="assets/img/имя.jpg" alt="ФИО" loading="lazy"></div>`.
- **Галерея** — `gallery.html`: изображение, подпись в `figcaption` и `data-caption` для просмотра.
- **Достижения** — `achievements.html`: изображение, год, заголовок и описание.
- **Документы** — `index.html`, блок `#documents`: название, ссылка и размер файла.
  Новый PDF кладите в `assets/docs/` и указывайте его путь и в ссылке-названии,
  и в кнопке скачивания.
- **Порядок обращения** — `index.html`, блок `#procedure`: часы приёма, шаги и сроки.
- **Часы приёма бейджа** — `assets/js/script.js`: расписание в константах в начале файла.
- **Социальное превью** — `assets/img/og-image.png` (1200×630), ссылка на него
  в `<meta property="og:image">` на каждой странице.
